---
name: file-issue
description: File an issue on nan-language/nan, a bug or a feature request, with the structure of its template and its labels
---

1. Search the issues, open and closed, for the defect or the gap; when one covers it, add to that issue instead.
2. Write the issue as `.github/ISSUE_TEMPLATE/bug.md` says when NaN does something wrong, or as `feature.md` says when it lacks something: its title, its first line and its sections, without the template's comments.
3. Set the labels the template names in the call that files it.
